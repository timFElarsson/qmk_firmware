# banzai

![banzai](Image will be coming)

This is my very own keyboard, designed from the ground up PCB and all, by me.
I wanted to make one that fit my hands, with splay, column stagger and the buttons I want.

* Keyboard Maintainer: [Tim Larsson](https://github.com/timFElarsson)
* Hardware Supported: *Custom Made PCB, Liatris (RP2040 Pro Micro drop-in replacement)*
* Hardware Availability: *Custom Made by me, not available*

Make example for this keyboard (after setting up your build environment):

    make banzai:default

Flashing example for this keyboard:

    make banzai:default:flash

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).
